# 🚢 Titanic - Machine Learning from Disaster

My first Kaggle machine learning competition, completed as part of my journey into **Data Science and Machine Learning**.

The goal of this project was to build a machine learning model that predicts whether a passenger survived the Titanic disaster based on passenger information.

## 📌 Competition

**Kaggle:** Titanic - Machine Learning from Disaster

The competition provides passenger information from the Titanic and asks participants to predict survival for passengers in the test dataset.

---

## 🎯 Project Objective

The main objective of this project was to understand and implement a complete machine learning workflow:

- Understand the dataset
- Perform exploratory data analysis
- Handle missing values
- Select useful features
- Encode categorical data
- Split data into training and validation sets
- Train a machine learning model
- Evaluate model performance
- Generate predictions for unseen data
- Create a Kaggle submission
